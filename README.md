# 🏠 אתר להשכרה ולמכירה של דירות

מערכת אינטרנטית לניהול, פרסום וחיפוש דירות להשכרה ולמכירה.

## ✨ תכונות עיקריות
- **יצירת חשבון משתמש** – הרשמה וניהול חשבון אישי.
- **צפייה בדירות** – הצגת דירות המוצעות להשכרה ולמכירה.
- **סינון דירות** – חיפוש וסינון לפי מאפיינים וסטטוסים.
- **ניהול סטטוסים** – עדכון מצב הדירות בהתאם לזמינותן.
- **שליחת משובים** – אפשרות לשליחת משוב על המערכת.

## 🛠️ טכנולוגיות
- Python
- SQL

## 🎯 מטרת הפרויקט
פיתוח פלטפורמה נוחה וידידותית למשתמש, המאפשרת לפרסם, לחפש ולנהל מודעות של דירות להשכרה ולמכירה במקום אחד.
